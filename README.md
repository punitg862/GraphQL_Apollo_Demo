# GraphQL_Apollo_Demo

A minimal iOS application demonstrating the integration of **GraphQL** using the **Apollo iOS** library, built with a clean **MVVM** architecture and a **Repository** pattern.

## 🎯 Purpose

This project serves as a blueprint for:
- Setting up Apollo iOS via Swift Package Manager (SPM).
- Using the Apollo CLI for safe, type-safe code generation.
- Implementing a clean separation of concerns (UI, Business Logic, Data).
- Fetching data from a public GraphQL API (Countries API) for testing.

## 🏗️ Project Structure

The project is organized into the following folders:

| Folder | Purpose |
| :--- | :--- |
| **`GraphQL/`** | Contains the schema and query files that the Apollo CLI reads. |
| **`Network/`** | Holds the `ApolloClient` instance (the core network layer). |
| **`Models/`** | Contains the custom Swift models used by the UI. |
| **`Data layer/`** | Implements the Repository protocol to fetch and map data. |
| **`ViewModel/`** | Manages UI state, loading, and error handling. |
| **`View/`** | Displays the data to the user using SwiftUI. |

## 🚀 Getting Started

### 1. Install Apollo via SPM
- Open Xcode and create a new SwiftUI project.
- Go to **File > Add Package Dependencies...**
- Paste the Apollo URL: `https://github.com/apollographql/apollo-ios`
- Ensure the `Apollo` library is linked to your target.

### 2. Create the GraphQL Files
- Create a `GraphQL/` folder in your project.
- Place your `schema.graphqls` and `Countries.graphql` files inside it.
- **Note:** The schema must match the API you are calling.

### 3. Install the Apollo CLI
- In Xcode, right-click on your project folder.
- Select **"Install CLI"** from the context menu.
- Open your terminal and navigate to your project root.

### 4. Generate Swift Code
Run these commands in your terminal:
